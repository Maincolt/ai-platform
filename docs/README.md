# Documentation

This directory is the source of truth for platform documentation.

Use it for architecture, operating guidance, contribution guidance, and other
long-lived project knowledge. Documentation should evolve in the same changeset
as the behavior or decision it describes.

## Contents

- `architecture/README.md` — logical platform architecture, component
  responsibilities, boundaries, and collaboration flow
- `architecture/decisions/` — Architecture Decision Records for significant
  technical and structural choices
- `testing/README.md` — platform test levels, execution categories, and
  validation expectations

Major architectural choices belong in `architecture/decisions/`.
